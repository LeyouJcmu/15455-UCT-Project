01 / One question

Mahaney's theorem.

First, what does sparse mean?

Definition

A sparse set

A set S is sparse if, for every input length n, at most polynomially many strings of length n are in S.

There may be up to 2n strings of length n in total. A sparse set contains only a polynomial number of them.

Mahaney's theorem

One question

If a sparse set is NP-hard under polynomial-time many-one reductions, then P = NP.

A many-one reduction turns an instance of one problem into a single instance of another. So if one sparse set can represent every problem in NP this way, then P and NP must be equal.

02 / A fixed number of questions

The stronger theorem.

The stronger result allows several questions about the sparse set, but the number must be fixed.

Stronger Mahaney's theorem

Nonadaptive questions

If SAT can be decided in polynomial time using a fixed constant number of nonadaptive queries to a sparse set, then P = NP.

SAT asks whether a Boolean formula can be made true. “Nonadaptive” means all questions to the sparse set are prepared before any answers are received.

This strengthens Mahaney's theorem: it permits more than one question, while keeping their number constant.

The stronger result is due to Ogiwara and Watanabe.
