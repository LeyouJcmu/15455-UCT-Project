Page 4 / Sparse sets

Every known NP-complete set is dense.

Every NP-complete problem anyone has found turns out to be the same problem in disguise, and all of them are dense. This page defines sparse sets, explains that observation and the conjecture it led to, and shows why the conjecture predicts that no sparse set is NP-complete. It also sets up the self-reducibility of SAT, the tree that Mahaney’s proof searches. Mahaney’s Theorem proves that prediction from the weaker assumption $\P \ne \NP$.
