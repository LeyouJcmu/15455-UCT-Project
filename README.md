# LeyouJcmu.github.io

A GitHub Pages teaching site on NP-intermediate problems, Ladner's Theorem and Mahaney's Theorem.

## Pages

| # | File | Topic |
|---|------|-------|
| 1 | `1_home.html` | Home: is NP split cleanly in two? |
| 2 | `2_npi.html` | NPI and Ladner's Theorem (full proof) |
| 3 | `3_sparse.html` | Sparse and tally languages, self-reducibility of SAT, the Berman–Hartmanis conjecture |
| 4 | `4_mahaney.html` | Mahaney's Theorem, Part I: statement and strategy |
| 5 | `5_mahaney-proof.html` | Mahaney's Theorem, Part II: the proof |
| 6 | `6_consequences.html` | Consequences and extensions |
| 7 | `7_glossary.html` | Glossary and references |
| – | `authoring.html` | Authoring guide with live examples (not linked from the site) |

Shared files: `style.css` (all styling), `site.js` (navigation, Markdown + LaTeX rendering, footnotes, edit mode), `media/` (images and videos).

The header navigation and the previous/next links are generated from the `PAGES` list at the top of `site.js`. To add a page, copy an existing page and add an entry there.

## Editing the text

Long-form text lives in Markdown blocks inside each HTML file:

```html
<script type="text/markdown" data-md="ladner-lemmas">
## The five lemmas
Ordinary **Markdown** with $\LaTeX$ math.
</script>
```

Edit between the tags, save and reload. Do not type a closing `script` tag inside a block.

### Syntax cheat sheet

| What | Syntax |
|------|--------|
| Inline math | `$c_S(n) \le p(n)$` |
| Display math | `$$ ... $$` on its own lines (also `\[ ... \]`) |
| Literal dollar | `\$` |
| Theorem box | `:::theorem (Ladner, 1975)` … `:::` |
| Other boxes | `lemma`, `claim`, `corollary`, `proposition`, `conjecture`, `definition`, `proof` (adds ∎), `intuition`, `remark`, `note`, `example`, `warning`, `takeaways`, `box`, `why` (motivation before a lemma), `status` (progress after a step) |
| Nested boxes | `::::lemma 1: Title` … `:::proof` … `:::` … `::::` |
| Figure | `![alt text](media/file.png "Caption with $math$")` on its own line |
| Narrower figure | add `{width=60%}` or `{width=400}` after the `)` |
| Video | `@[alt text](media/clip.mp4 "Caption")`, or a YouTube/Vimeo URL |
| Footnote | `text[^name]` plus a line `[^name]: Footnote text.` (one line, anywhere on the page) |
| Fixed heading anchor | `## Lemma A {#lemma-a}` |
| Interactive figure | `@[viz](mahaney-search "Caption")` on its own line (see below) |

LaTeX shortcuts such as `\P`, `\NP`, `\SAT`, `\redm`, `\iso`, `\enc{\varphi, y}` are defined in `MACROS` in `site.js`; add your own there. Math also works in the plain-HTML parts of a page (hero text, home-page cards).

### Edit mode (live preview in the browser)

Add `?edit` to any page's address, for example `2_npi.html?edit`. Each block gets an **Edit** button with a toolbar for math, boxes, images, videos and footnotes, and the page re-renders as you type. You can drag an image or video onto the text box to insert it (then copy the file into `media/`).

Edits are drafts saved in your browser only. To keep one, click **Copy Markdown**, paste it over that block in the HTML file, save, reload, then click **Revert to file** to clear the draft.

## Interactive figures

`viz.js` defines step-through animations. Embed one in any Markdown block with a line of its own:

```
@[viz](NAME "Caption")
@[viz](NAME?option=value "Caption")
```

| NAME | What it shows | Used on |
|------|---------------|---------|
| `ladner-h` | H(n) catching machines one by one; toggle the impossible "M₃ is fast" world | Ladner, "The idea" |
| `ladner-shrink` | The square-rooting recursion of Lemma 5 | Ladner, Goal (iii) |
| `left-set` | Click leaves to set the satisfying assignments; the left set on every level (Lemma B) | Mahaney I |
| `mahaney-search` | The pruned search on made-up instances; options `r=1`, `r=2`, `r=3`, `mode=fortune` | Mahaney II, Extensions |

To try a widget on its own, open `tools/viz-test.html?w=NAME&s=5` (it clicks Step five times).

## Hero graphics

The graphic at the top right of each page is an inline SVG inside `<figure class="hero-figure">`. It is generated by `tools/make_figures.py`, one function per page. To change a graphic, edit that function and run:

```
python tools/make_figures.py .
```

This rewrites only the `hero-figure` block in each page. You can also edit the SVG in a page directly, but the next run of the script will overwrite it. Captions may use `$math$`.

## Run locally

Open any `.html` file in a browser (internet access is needed for KaTeX and marked, which load from jsDelivr), or serve the folder with `python -m http.server`.

## Publish

In the repository's GitHub settings, enable Pages for the branch containing these files. There is no build step. The root `index.html` only redirects to `1_home.html`, so the site's bare URL still works.
