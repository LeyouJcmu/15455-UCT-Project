# LeyouJcmu.github.io

A GitHub Pages teaching site introducing NP-intermediate problems (NPI), Ladner's theorem, and candidate problems.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Publish

In the repository's GitHub settings, enable Pages for the branch containing `index.html`. The site is a static page and does not require a build step.
