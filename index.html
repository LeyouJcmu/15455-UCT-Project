01 / The definitions

What are P and NP?

These classes describe decision problems: questions with a yes-or-no answer.

P

Polynomial time

Definition: P is the class of decision problems that a deterministic algorithm can decide in polynomial time. This means its running time is at most O(nk) for some constant k, where n is the input length.

NP

Polynomial-time verification

Definition: NP is the class of decision problems with a deterministic polynomial-time verifier V and polynomial q such that x is a yes-instance exactly when some certificate y, with |y| ≤ q(|x|), makes V(x, y) accept. Equivalently, a nondeterministic algorithm can decide the problem in polynomial time.

P ⊆ NP

Why P is inside NP

If we can solve a problem quickly, we can also check a proposed answer quickly. So every problem in P is also in NP.

02 / The open problem

Does P equal NP?

This is one of the biggest unanswered questions in computer science.

The question

Can every quickly checked answer also be found quickly?

P = NP?

What we know: P is contained in NP. We do not know whether every problem in NP is also in P.

If P = NP: Every problem whose solutions can be checked quickly can also be solved quickly.

If P ≠ NP: Some problems in NP have no polynomial-time solving algorithm.
