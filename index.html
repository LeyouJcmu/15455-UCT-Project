01 / The setup

Three ideas to begin.

P and NP describe how quickly problems can be solved or checked.

P

Can be solved quickly

A problem is in P if an algorithm can solve it in polynomial time.

NP

Can be checked quickly

For problems in NP, a short proof of a yes-answer can be checked in polynomial time. P is inside NP.

P ≟ NP

Still unknown

We do not know whether P = NP. If they differ, some NP problems cannot be solved in polynomial time.

02 / The key result

Ladner's theorem

If P ≠ NP, there is a problem in NP that is neither in P nor NP-complete.

This means there is a middle ground: a problem that is not in P, but is also not NP-complete. Such a problem is called NP-intermediate, or NPI.

The proof builds a special problem that is hard enough to stay outside P, but is not hard enough to be NP-complete. It does not show that any familiar problem is NPI.

03 / Sparse sets

Mahaney's theorems.

A sparse set has only polynomially many yes-strings of each length.

Mahaney's theorem

One question

If a sparse set is NP-hard under polynomial-time many-one reductions, then P = NP.

If every problem in NP can be turned into one question about a sparse set, then P and NP are equal.

Stronger Mahaney's theorem

A few questions

If SAT can be solved in polynomial time with a fixed number of questions to a sparse set, then P = NP.

SAT asks whether a logic formula can be made true. All questions must be chosen before seeing any answers. This strengthens Mahaney's theorem: it allows more than one question, but still only a fixed number.

04 / Possible examples

Problems that might fit.

These problems might be NPI, but no one knows for sure.

Graph isomorphism

Are two graphs the same after renaming their points? A proposed renaming is easy to check. We do not know if the problem is in P or NP-complete.

NPI candidate

Integer factorization

Given numbers N and k, is there a divisor of N between 2 and k? A proposed divisor is easy to check. It is not known to be in P or NP-complete.

NPI candidate

Note: We do not know if either problem is NPI. Ladner's theorem says some NPI problems exist if P ≠ NP, but these examples may or may not be among them.
